\section{工作总结}\label{sec:summary}

本文提出并实现了一个基于物理信息神经网络（PINN）与大语言模型（LLM）的统一期权定价框架，将 BSM、CEV、Heston 三大经典期权定价模型纳入同一体系。

在 PINN 部分，三大模型共用统一的复合损失函数结构（PDE 残差 + 终值条件 + 边界条件），通过自动微分精确计算 PDE 残差，无需网格剖分。BSM 和 CEV 模型采用门控网络架构，浅层分支捕捉线性特征，深层分支捕捉平值附近的非线性特征；Heston 模型采用更深的全连接网络，并结合 ICPINN 硬约束输出变换，确保终值条件在机器精度下精确满足。

在 LLM 部分，引入 DeepSeek API 作为智能路由层，通过结构化 JSON 输出实现可靠的参数提取和模型选择，支持中英文自然语言输入，使非专业用户无需了解模型细节即可完成期权定价。

实验结果表明，BSM-PINN 在解析解验证下达到 MAE=0.056 的精度；CEV-PINN 正确捕捉了杠杆效应；Heston-PINN 在二维随机波动率场景下实现了可用的定价精度。LLM 路由层在测试用例上实现了 100\% 的模型选择准确率。

\section{局限性与未来工作}\label{sec:future}

本文工作存在以下局限性，可在未来工作中改进：

\textbf{精度有待提升}：CEV 和 Heston 模型的相对误差（约 11\% 和 24\%）高于工程应用要求。可通过增加训练轮数、引入自适应配点采样（如 RAR 方法）、或采用更先进的网络架构（如 Fourier 特征网络）来改善精度。Heston 模型误差偏高的根本原因在于二维 PDE 的解在 $v \to 0$ 附近存在奇异性（Feller 边界），普通全连接网络难以精确捕捉这一区域的行为，未来可引入专门的边界层处理技术。

\textbf{仅支持欧式看涨期权}：当前框架仅针对欧式看涨期权，未来可扩展至欧式看跌期权（通过 put-call parity 转换）和美式期权（需处理自由边界问题）。美式期权的 PINN 求解需要在损失函数中加入互补性约束（complementarity constraint）：$\min(\mathcal{F}[V],\, V - \phi(S)) = 0$，即期权价值不得低于立即执行价值，这等价于在配点处对 $V < \phi(S)$ 的违约施加惩罚。

\textbf{参数固定与参数化 PINN}：当前 PINN 模型针对固定参数集训练，若参数变化（如不同的 $\sigma$ 或 $K$）需要重新训练。一个自然的改进方向是参数化 PINN（Parametric PINN）：将模型参数（$\sigma$、$\kappa$、$\theta$ 等）作为额外输入，训练一个覆盖整个参数空间的统一网络，实现"一次训练、任意参数推断"。Hainaut 与 Casas\citep{hainaut2024heston} 在 Heston 模型上探索了这一方向，证明了参数化 PINN 在随机波动率定价中的可行性。然而，参数化 PINN 面临两个主要障碍：其一，输入维度随参数数量线性增长，Heston 模型的参数空间达到 8 维（$S, v, t, \kappa, \theta, \xi, \rho, v_0$），训练所需的配点数和计算时间大幅增加；其二，不同参数组合下 PDE 的解的形态差异显著，单一网络难以同时捕捉所有情形。这是未来工作的重要方向。

\textbf{统一多模型框架}：本文对 BSM、CEV、Heston 分别训练独立的 PINN，三个模型的 PDE 算子不同，无法直接共享网络权重。未来可探索基于元学习（meta-learning）的方法，利用三个模型之间的结构相似性（均为 Black-Scholes 类 PDE）加速训练。

\textbf{LLM 参数提取的鲁棒性}：当前系统对模糊或不完整的自然语言输入处理能力有限。未来可引入多轮对话机制，让 LLM 主动向用户询问缺失参数。此外，当前 LLM 路由规则基于关键词匹配（如"Heston"、"随机波动率"），对于隐含的模型选择需求（如用户描述"指数期权，需要拟合波动率微笑"但未明确说明模型名称）处理能力有限，未来可通过 few-shot 示例或微调提升路由准确率。

\textbf{实时定价场景}：当前系统的主要延迟来自 LLM API 调用（约 1-2 秒）。对于高频交易场景，可考虑将 LLM 替换为轻量级的规则解析器，仅保留 PINN 的快速推断能力（单次推断约 2 ms）。另一方向是将训练好的 PINN 模型导出为 ONNX 格式，部署在 C++ 推断引擎上，进一步将推断延迟压缩至微秒级，满足做市商的实时定价需求。

\textbf{多市场数据支持}：本文实现了美股（yfinance）、A 股（akshare）和港股（yfinance）三个市场的参数校准适配器，但港股历史期权数据稀缺，回测仅能依赖合成数据。未来可接入 Wind、Bloomberg 或 HKEX 官方数据接口，获取完整的历史期权链，支持更严格的跨市场回测验证。

\section{本章小结}\label{sec:conclusion_summary}

本文提出的 LLM+PINN 统一期权定价框架，在以下三个维度上对现有工作做出了贡献：

\textbf{技术层面}：将 BSM、CEV、Heston 三大经典期权定价模型统一在 PINN 框架下，共用损失函数结构和训练流程，Heston 模型额外采用 ICPINN 硬约束确保终值条件精确满足。通过自动微分，希腊字母可与期权价格在同一次前向传播中同时计算，无需额外推导。

\textbf{交互层面}：引入 LLM 作为自然语言接口，用户无需了解模型细节即可完成期权定价。LLM 的职责被精确限定为"模型选择"，数字参数由市场数据 API 直接查询，实现了职责分离和系统可靠性的提升。

\textbf{工程层面}：实现了三市场（美股/A 股/港股）的数据适配器，基于适配器模式的设计使新增市场只需实现一个子类，无需修改校准逻辑。滚动回测框架支持对 PINN 定价精度的历史验证，为系统在真实市场条件下的适用性提供了实证依据。
